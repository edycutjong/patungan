Pertanyaan · questions

What a judge would ask

Is it on QIE mainnet?

Yes. The contract is 0x2f4646D52a5393E239f5b880411dC2CA2D945F31 on QIE mainnet; every pool, join, payout and refund is on mainnet.qie.digital.

What if the group doesn't fill?

Then nobody is paid. After the deadline each member can take their QUSDC back with claimRefund, and anyone can call refundAll to return everyone's at once (in batches for large pools). The organizer can also cancel early, which opens the same refunds. A seat paid in QIE comes back as QUSDC.

Can the organizer run off with the money?

The organizer never holds it. QUSDC sits in the contract until the last seat, then goes to the payee fixed when the pool was created. Patungan has no admin key and no withdraw function. The one risk outside our code is QUSDC's issuer role, listed above.

Why swap QIE inside the join?

Members who hold QIE can pay without a separate swap. joinWithQIE buys exactly the seat price and returns unused QIE in the same transaction. It reverts if the swap would cost more than the Oracle's fair value plus a guard set at deploy (1,500 bps in the fork runs; the contract caps it at 2,000).

What does the .qie name do?

The organizer types the payee as a name such as test.qie. Patungan resolves it through Zone's domainOwnerByName at creation and stores the address. If the name points somewhere else by the time the transaction is mined, creation reverts with PayeeChanged.

What is mocked, and who are the users?

The demo path is not mocked: the browser runs and script/local-flow.sh use a mainnet fork. 50 of the 74 contract tests use mocks for speed and fuzzing. There are no real users yet; pools the builder creates will be labelled as builder wallets (the app already supports the label).
